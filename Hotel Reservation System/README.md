# 🏨 Hotel Reservation System

A Java-based Hotel Reservation System developed as part of the **CodeAlpha Java Programming Internship**.

## ✨ Features

- 🏨 View available rooms
- 🔍 Search rooms by category
- 🛏️ Book hotel rooms
- ❌ Cancel reservations
- 💳 Simulate payment
- 📋 View all reservations
- 💾 Save reservation details using File I/O
- ✅ Input validation

## 🏷️ Room Categories

- Standard
- Deluxe
- Suite

## 🛠️ Technologies

- Java
- OOP
- ArrayList
- Loops
- If-Else
- Scanner
- File I/O

## 📂 Project Files

- `Main.java` — Main program and menu
- `Room.java` — Manages room details
- `Reservation.java` — Manages reservation and payment details
- `reservations.txt` — Stores reservation information

## 🎯 Purpose

This project demonstrates the use of **Object-Oriented Programming, collections, user input, reservation management, payment simulation, and File I/O** in Java.
